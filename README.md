# 玄彬 HYUNBIN

玄彬时尚男装官网的公开发布仓库。

- 官网首页：[hyunbin-garment.github.io](https://hyunbin-garment.github.io/)
- 招商手册：[在线图册](https://hyunbin-garment.github.io/brochure/)

`site.zip` 包含完整官网、滚动叙事素材和保留的招商图册。原图册PDF与图片的旧根路径继续保留，已分享的文件链接无需改变。

提交到 `main` 或在 Actions 页面手动运行工作流（Workflow）后，GitHub Actions 将发布包解压并部署到 GitHub Pages。网站是否已更新，以最新部署任务的成功状态为准。

工艺画面是概念叙事，成衣概念图不对应在售款式；门店资料将于核实后补充。素材来源与权利说明见 [ASSET_LICENSES.md](ASSET_LICENSES.md)。品牌标识、招商图册及第三方素材分别保留其权利，本仓库不授予通用开源使用权。
